# ПИКЕТ 2.0.35

- Экран настроек приведён к рабочему порядку: первым открывается «Приказ по скоростям».
- «Путевой норматив» переименован в «Приказ по скоростям».
- Кнопка «Удалить все ограничения» теперь расположена сразу после приказа по скоростям.
- Далее последовательно расположены настройки предупреждений, обновления ПИКЕТ и диагностика поездки.
- Такой же порядок общих разделов перенесён в Apple Web; недоступные в браузере Android-функции по-прежнему скрыты.
- Добавлены автоматические проверки, защищающие порядок карточек от случайной перестановки в следующих версиях.
