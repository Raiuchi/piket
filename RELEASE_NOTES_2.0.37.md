# ПИКЕТ 2.0.37

- Резервный GPS теперь удерживается до устойчивого восстановления основного потока и перезапускается при отсутствии координат.
- Добавлен отдельный запрос свежей координаты, когда системная геолокация зависла после РЭБ или слабого сигнала.
- Точные GPS-точки больше не отклоняются только из-за небольшого расхождения с нарисованной осью пути.
- Устаревшие сведения о спутниках очищаются и не создают ложное впечатление рабочего GPS.
- При скачке восстановленной позиции через короткое ограничение приложение всё равно выдаёт красное оповещение.
- После остановки и повторного запуска карточка перегонного времени ждёт актуальную нативную позицию.
- Кнопка «Стоп» требует подтверждения, чтобы поездка не завершалась случайным касанием.
- Приказ по скоростям использует точные километры и пикеты, показывает текущую позицию и координаты станций.
- Для обратного маршрута Петрозаводск → Дача Долгорукова открывается правильная последовательность приказа сверху вниз.
- Проверены прямые и обратные переходы всех маршрутов, предупреждения и ограничения скорости.
