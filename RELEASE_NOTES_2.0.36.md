# ПИКЕТ 2.0.36

- Кнопка «Удалить все ограничения» перенесена из настроек во вкладку «Список».
- Очистка теперь находится непосредственно рядом со списком внесённых ограничений и отображается после него.
- В настройках остались только приказ по скоростям, параметры предупреждений, обновления и диагностика поездки.
- Новый порядок синхронизирован с Apple Web и защищён автоматическими проверками.
