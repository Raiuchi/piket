# ПИКЕТ 2.0.38

- На экране поездки появилась единая «Рабочая сводка»: приказ по скоростям, перегонное время и ближайшее ограничение находятся рядом с километражем.
- Исправлено залипание приказа по скоростям на прежней станции: APK использует актуальную координату Android, а не устаревшее состояние видимого экрана.
- Строка приказа переключается последовательно с учётом километра, пикета, станции и направления движения.
- Небольшие колебания и поправки GPS больше не возвращают активную строку приказа назад.
- Нажатие на карточку приказа открывает текущую строку, карточка времени ведёт к подробному графику, карточка ограничения — к списку.
- Кнопка «Удалить все ограничения» скрыта, пока список ограничений пуст.
- Изменения синхронизированы между APK и Apple Web; веб-кэш обновлён для получения новой версии.
- Пройдены модульные, маршрутные, браузерные и Android-эмуляторные проверки.
