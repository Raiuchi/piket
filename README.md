## Цифровая кабина

ПИКЕТ объединяет премиальный приборный интерфейс, расчёт железнодорожной позиции и персональные предупреждения в одном автономном Android-приложении. После калибровки по километровому столбу приложение сопоставляет координаты телефона с геометрией выбранного маршрута и показывает текущий километр, пикет и метр.

### Возможности

- спортивный приборный интерфейс PIKET RS в графитово-красной палитре;
- выразительный спидометр с симметричной шкалой и визуальными состояниями движения;
- 10 оцифрованных GPS-маршрутов с поддержкой обоих направлений;
- ручная калибровка и автоматическое определение позиции;
- персональный список временных ограничений;
- голосовые, звуковые, вибрационные и цветовые оповещения;
- справочник скоростей для поддерживаемых составов и участков;
- локальное хранение данных без регистрации и серверной части;
- фоновая Android-служба для работы при свёрнутом приложении и погашенном экране.

## Интеллектуальная работа с GPS

Навигационный модуль оценивает свежесть и точность координат, скорость по Doppler, качество GNSS, принадлежность выбранному маршруту и физическую правдоподобность движения.

При потере сигнала приложение сохраняет расчёт движения. После возвращения GPS оно требует согласованную серию качественных координат, отбраковывает нереалистичные скачки скорости и сразу возвращает расчёт к подтверждённой позиции, если накопленный уход достиг 50 метров. Небольшой шум до 50 метров сглаживается. Физическое положение на линии отделено от официальной километровой шкалы: подтверждённые смены километража отображаются ступенью строго по `listPoints.txt`, не воспринимаются как GPS-скачок и не искажают расстояние до ограничения. Индивидуальная полевая поправка хранится отдельно для каждого маршрута и формируется после ручной сверки по столбу.

Программная фильтрация повышает устойчивость расчёта, но не может устранить радиопомехи или заменить отсутствующий спутниковый сигнал. Фактическая точность зависит от телефона, разрешений Android, энергосбережения, геометрии маршрута и условий приёма.

## Сборка

Приложение построено на Java и Android WebView. Для локальной release-сборки требуются JDK 17, Android SDK и параметры подписания.

```text
gradlew.bat testReleaseUnitTest
gradlew.bat assembleRelease
```

Автоматическая сборка и публикация релиза выполняются через GitHub Actions. Ключ подписи в репозитории не хранится.
